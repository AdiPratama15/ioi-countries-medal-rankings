# IOI Countries Medal Rankings

Interactive country rankings for the International Olympiad in Informatics (IOI).

## Features

- Sorts countries by medal performance in descending order
- Ranking priority:
  1. Gold
  2. Silver
  3. Bronze
  4. Total
- Equal values share the same rank
- Search filter for country names
- Clear color distinction for Gold, Silver, Bronze, and Total columns
- Full label text for medal columns:
  - Gold
  - Silver
  - Bronze
  - Total

## Data Source

This page is adapted from IOI statistics data:

- https://stats.ioinformatics.org/countries/
